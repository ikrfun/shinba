# デスクトップ試作

Node.js と npm を用意し、プロジェクトのルートで次を実行します。

```sh
npm install
npm run dev
```

`Cmd+O`（Windows/Linux は `Ctrl+O`）で作業対象のフォルダを選び、ボードにカードを追加できます。ボードとコードの変更は自動保存します。ボードは選択したフォルダの `.shinba/boards/main.json` に保存します。ファイルツリーで TypeScript または JavaScript のファイルを開くと、シンボルを取得します。シンボルを選んでからカードのボタンを押すと、カードに関連づけられます。コードの定義へ移動するには F12 を使います。`Ctrl+`` でターミナルを開閉し、Git などのコマンドを実行できます。

現在は単一ボードの試作です。複数ボード、HTML プレビュー、言語サーバー設定の追加画面、外部変更の自動反映は未実装です。コードの保存前にはファイルの外部変更を確認し、変更されていれば保存を中止します。ボードの保存はリビジョンを比較しますが、同時書き込みの排他は未実装です。重要なプロジェクトではバックアップを取ってください。

コードエディターでは Vim モードが初期状態で有効です。`i` で入力を開始し、`Esc` または `Ctrl+[` で Normal モードに戻ります。ツールバーの「Vim 有効／無効」で切り替えられ、設定はアプリの個人設定として保存されます。

カードの「Parent」から親カードを選ぶと入れ子になり、「None」で外せます。子カードがある親は、子を外してから削除してください。
