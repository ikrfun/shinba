## 位置づけ

`.agents/skills/design-workshop/` は、コンセプトや操作感を探るために作った試作です。十分な要件定義や設計を経た実装ではありません。今後の仕様やアーキテクチャの基準として扱わず、設計を進める際の参考にします。

## 保存と agent 連携

試作のボードはブラウザの保存領域に保存され、JSON で書き出し・読み込みができます。coding agent と内容を共有する場合は、JSON を受け渡します。`scripts/` には書き出したボードに提案や実行結果を追加する補助スクリプトがあります。

ブラウザの保存領域は新しい場所に HTML を移しただけで確実に引き継がれるとは限りません。現在使用中のボードがある場合は、移行元で JSON を書き出し、移行先で読み込んでください。読み込みは表示中のボードを置き換えます。

MCP を使った直接連携、アプリ内からの agent の起動、実装コードの実行は、この試作では完成していません。これらの設計は今後検討します。
