エクスプローラー

フォルダを選ぶと、ファイルを一覧して閲覧できます。フォルダはブラウザ内だけで読み取ります。選択したファイルには機密情報が含まれる場合があります。

設計中の構成

ボードの「コード構成」カードをツリー表示します。実ファイルは作成しません。

カードを追加
ボードの実行ケース
入力・実行前の状態・期待結果を記録し、JSON を coding agent に渡します。agent が実装を実行して結果を追加した JSON を読み込むと、ここに表示します。
本文と大きさ
本文は「編集」「表示」で切り替えます。見出し、箇条書き、太字、コード、リンクに対応しています。カード右下をドラッグすると幅と高さを変更できます。
複数カードの移動
ボードの空白部分からドラッグして選択し、選択したカードの見出しをドラッグします。Shift を押しながら見出しをクリックして選択を追加・解除できます。
処理の入れ子
処理カードの見出しを、別の処理カードの上へドラッグすると、その中に配置します。外へ移動すると入れ子を解除します。
線でつなぐ
カード右端の丸から別のカードへドラッグします。または Shift を押しながら2枚の見出しを選び、C キーで選んだ順につなぎます。線をクリックして Delete キーで削除できます。
このボードの目的
考えるための問い
  • 誰が何をしたい？ 成功とは？
  • 入力と出力の項目・制約は？
  • 途中で失敗・再試行したら？
  • 別の設計案とその違いは？
  • 各ケースの期待結果をどうテストする？
ケース整理、スキーマ、処理の流れなどを別のボードに分けられます。JSON を書き出して coding agent に渡し、提案を追記した JSON を読み込むと図に反映できます。ブラウザ内の保存内容は agent から直接読めません。
